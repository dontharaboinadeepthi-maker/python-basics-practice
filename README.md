# Python Basics Practice

Beginner Python practice programs covering user input, variables, and simple calculations. I'll keep adding more programs as I learn.

## Programs

| File | Description |
|------|-------------|
| `q1_swap.py` | Greets the user by name, takes two values, and prints them before and after swapping |
| `q2_circle.py` | Calculates the area of a circle from a given radius |
| `q3_age.py` | Calculates age from the user's birth year |
| `q4_bakery.py` | Prints a personalized birthday message using the customer's name and favorite cake |
| `q5_interest.py` | Calculates simple interest from principal, rate, and time |

## How to Run

1. Make sure Python 3 is installed.
2. Clone this repository:
   ```
   git clone https://github.com/your-username/python-basics-practice.git
   ```
3. Go into the folder and run any program:
   ```
   cd python-basics-practice
   python q1_swap.py
   ```

## Concepts Practiced

- Taking input with `input()`
- Type conversion (`int()`, `float()`)
- Variables and arithmetic operators
- f-strings for formatted output
- Swapping variables
- Using the `datetime` module
